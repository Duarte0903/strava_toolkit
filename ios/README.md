# Samsung → Strava — iOS app

A native iPhone version of the desktop exporter. Import a Samsung Health export
`.zip`, browse/inspect workouts, export selected ones to **TCX/GPX** saved into
the app's Documents (visible in **Files**), then upload them yourself at
[strava.com/upload/select](https://www.strava.com/upload/select). No Strava API,
no account linking.

```
ios/
  StravaToolkitKit/     Swift package — all parsing / TCX / GPX / zip logic (verified)
  StravaToolkitApp/     SwiftUI app — UI on top of the package (build in Xcode)
```

## What's verified vs. not

This was built on a machine with the Swift toolchain but **without Xcode**, so:

- ✅ **Core logic (`StravaToolkitKit`) is verified.** It's pure Foundation and
  was exercised end-to-end by a headless harness — parsing, TCX/GPX generation,
  detail charts data, filename format, distance scaling, and a real `.zip`
  inflate round-trip. Run it yourself:
  ```
  cd ios/StravaToolkitKit
  swift run stkcheck Tests/StravaToolkitKitTests/Fixtures
  # -> "26 checks passed, 0 failed"
  ```
  (With Xcode installed you also get the full swift-testing suite via `swift test`.)
- ⚠️ **The SwiftUI app is NOT built/run yet** — that needs Xcode + the iOS SDK,
  which weren't available here. The sources are complete but unverified until you
  open them in Xcode. Expect the possibility of a small fix or two on first build.

## Build & run the app

Prerequisites: **Xcode** (from the App Store), and an iPhone or the simulator.

### Option A — XcodeGen (recommended, reproducible)
The `.xcodeproj` is generated from `project.yml` and is **git-ignored**, so
generate it after cloning (and re-run it whenever files or `project.yml` change —
e.g. after the app icon was added):
```
brew install xcodegen
cd ios/StravaToolkitApp
xcodegen generate
open StravaToolkit.xcodeproj
```
Then in Xcode: select your iPhone (or a simulator), set your Signing Team under
**Signing & Capabilities** (a free Apple ID works for your own device), and press
**Run** (⌘R).

### Option B — Manual (no XcodeGen)
1. Xcode → **File ▸ New ▸ Project… ▸ iOS ▸ App**. Name it `StravaToolkit`,
   interface **SwiftUI**, language **Swift**. Delete the auto-created
   `ContentView.swift`/`…App.swift`.
2. Drag the files from `StravaToolkitApp/Sources/` into the project
   ("Copy items if needed" off; add to the app target).
3. **File ▸ Add Package Dependencies… ▸ Add Local…** and pick
   `ios/StravaToolkitKit`. Add the `StravaToolkitKit` library to the app target.
4. In the target's **Info** tab add two keys (both **Boolean = YES**):
   `UIFileSharingEnabled` and `LSSupportsOpeningDocumentsInPlace`
   (or drop in the provided `Info.plist` and set it as the target's Info.plist).
5. Set your Signing Team, then **Run**.

## Using it

1. Get the Samsung Health export `.zip` onto the iPhone — AirDrop from a Mac, or
   save it into the **Files** app (iCloud Drive / On My iPhone).
2. Open the app → **Open export…** → pick the `.zip`.
3. Filter / tap a workout to inspect (stats, HR & pace charts, GPS route).
   Swipe a row (or use the circle) to select it for export.
4. Choose **Auto / TCX / GPX**, tap **Export selected**.
5. Files land in **Files ▸ On My iPhone ▸ StravaToolkit ▸ strava_upload**.
   Open [strava.com/upload/select](https://www.strava.com/upload/select) in a
   browser and upload them.

## Notes

- **Auto** picks GPX when the workout has GPS, else TCX (same rule as the desktop).
- The core package has no third-party dependencies; zip reading uses Apple's
  `Compression` framework directly.

## App icon

The icon (a white running route rising to an arrow, on Strava orange) lives at
`StravaToolkitApp/Sources/Assets.xcassets/AppIcon.appiconset/` as a single
1024×1024 PNG — Xcode downsizes it for every slot. It's generated by
`tools/make_icon.swift`; tweak that and regenerate with:
```
swift ios/tools/make_icon.swift \
  ios/StravaToolkitApp/Sources/Assets.xcassets/AppIcon.appiconset/icon-1024.png
```
